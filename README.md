# Live Journal

A small website avatar that reacts to what you actually log — food, drink, exercise, mood, meditations, journal pages, and goals. Customize looks in Avatar Studio (body, hair, clothes, tattoos).

## Local

```bash
npm install
npm run dev
```

## Live

GitHub Pages: https://browc814-spec.github.io/live-journal/

## Notes

- Data stays in `localStorage` on this device
- Coffee/soda without food → jittery avatar until a meal is logged
- Weight goals bias reactions toward healthy meals + workouts
